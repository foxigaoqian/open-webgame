About the Fields of Mistria Wiki

An independent field guide built around current primary sources, useful player questions and a visible line between confirmed information and speculation.

What this site is

This site is an independent fan-created guide to Fields of Mistria. It is designed as a Wiki-style search resource for players looking for current release information, practical system explanations, beginner guidance, relationship information and patch context.

How facts are checked

For facts that can change, the site prioritizes NPC Studio's official website, FAQ, press kit and patch notes together with the official Steam listing. Version numbers, platform availability, release state and similar claims are date-stamped and treated as information that needs regular re-checking.

What we do not do

Fields of Mistria is a native Steam game. This site does not mirror the game files, present an unofficial clone as the real game, or place a Steam marketing page inside an iframe and call it playable. If an official browser build ever becomes available, that fact would need to be independently verified before the site architecture changed.

Editorial approach

Game mechanics are described only when official information supports them. Strategy pages may offer practical recommendations, but recommendations are labeled as guidance rather than presented as hidden official rules. Rumors and unannounced release dates are not padded into pages for SEO.
